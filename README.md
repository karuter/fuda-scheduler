# fuda-scheduler（札決め）

競技かるたの試合で使う50枚を、何試合分でも先に決めておくツールです。

## 決め方

札は小倉百人一首の歌番号1〜100で、1〜9番は「01〜09」、100番は「00」として扱います。

| 決め方 | 内容 | 組み合わせ |
|---|---|---|
| 1の位 | 0〜9から数字を5つ選び、1の位がその数字の札（10枚×5） | 252通り |
| 10の位 | 0〜9から数字を5つ選び、10の位がその数字の札（10枚×5） | 252通り |
| 3つの数字 | 0〜9から数字を3つ選び、その数字を含む札（必ず51枚）からランダムに1枚除く | 120通り |

- 各試合の決め方は、チェックした決め方から同じ確率で選びます
- 同じ決め方の中では、組み合わせを使い切るまで同じものは出ません

## 使い方

1. 試合数と使う決め方を選んで「札を決める」を押す
2. 予定はページのURLに保存されます。「リンクを共有」でLINEなどに送れば、部員全員が同じ予定を見られます
3. 各試合の日付は後から入れられます（入れるとURLも更新されるので、入れた後に共有し直してください）
4. 札をタップすると上の句を全文表示します。「印刷」で番号の一覧を印刷できます

## 開発

ビルド不要の静的サイトです（GitHub Pagesで公開）。

```bash
python3 -m http.server 8000   # http://localhost:8000 で確認
node test/check.mjs           # 全パターンで50枚になるかを検証
```
